# Между строк × От сердца

Многостраничный статический сайт авторского проекта Аллы и Насти.

## Страницы
- `index.html` — главная.
- `about.html` — авторы с графическими портретами.
- `tarot.html` — каталог раскладов Насти.
- `stories.html` — каталог авторских психологических сказок Аллы, создаваемых на основе раскладов Таро Насти.
- `matrices.html` — каталог матричных и родовых разборов Аллы.
- `mak.html` — совместные МАК-практики.
- `service.html?id=...` — отдельная страница выбранной услуги.
- `booking.html` — пошаговая форма предварительной заявки.
- `account.html` — демонстрационный кабинет.
- `library.html` — библиотека материалов.

## Визуальная система
Montserrat; глубокий бордовый, графит и золото; компактная сетка, градиентные панели, объёмные кнопки и плавные переходы между отдельными HTML-экранами. Портреты в `assets/` подготовлены в графической манере на основе фотографий, предоставленных авторами; портрет Аллы обновлён с более мягкой реалистичной иллюстративной обработкой.

## Ограничения прототипа
Это статический frontend на GitHub Pages. Заявки сохраняются в localStorage браузера и не отправляются авторам; синхронизации между устройствами, защищённой серверной авторизации, серверного календаря реальных свободных слотов, платежей и уведомлений пока нет. Личный кабинет демонстрационный: локальная регистрация и вход по логину/паролю, данные и хеш пароля хранятся только в этом браузере. Не вводите реальные чувствительные данные. Для коммерческого запуска потребуется серверная часть, база данных, безопасная авторизация и обработка персональных данных, подтверждение записи и подключение уведомлений.

GitHub Pages публикует содержимое корня ветки `main`.
