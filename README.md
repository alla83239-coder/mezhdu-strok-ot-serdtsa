# Между строк × От сердца

Адаптивный фронтенд-прототип авторской платформы Аллы и Насти.

## Файлы
- `index.html` — страницы, разделы, форма записи и кабинет.
- `styles.css` — адаптивный дизайн.
- `app.js` — демо-логика заявок и кабинета.

## Просмотр
Откройте `index.html` в браузере. Шрифты и фоновая фотография загружаются из внешних источников при наличии интернета.

## Демо-функции
- Каталог направлений: матрицы, Таро, МАК «Карма Рода».
- Форма заявки с выбором автора, даты и времени.
- Сохранение заявок в localStorage текущего браузера.
- Демо-личный кабинет и панель администратора.
- Изменение статусов и экспорт CSV.

## Ограничения
Это статический прототип, а не готовый публичный сервис. Нет серверной авторизации, общей базы данных, реальной проверки свободных слотов, подтверждений, оплаты, Telegram/email-уведомлений или защищённого хранения персональных данных. Данные доступны только в том браузере, где созданы. До коммерческого запуска потребуется backend, база данных, безопасная авторизация, защита данных, серверная логика расписания, политика конфиденциальности и согласия на обработку данных. Цены, расписание и отзывы не выдуманы — их нужно согласовать с авторами.
