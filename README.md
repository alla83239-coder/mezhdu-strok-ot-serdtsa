# Между строк × От сердца

Адаптивный статический прототип авторской платформы Аллы и Насти.

## Визуальная система
- Восстановлен фотографический фон первого экрана с бордовой цветокоррекцией.
- Добавлены иллюстрированные авторские портреты Насти и Аллы (`assets/portraits.js`, WebP data URIs).
- Добавлены ссылки на VK Аллы и Telegram/прайс Насти.
- Основной шрифт: Montserrat.
- Палитра: глубокий бордо, графитовые оттенки и золото.
- Градиентные поверхности, объёмные CTA-кнопки, лёгкие hover-состояния.
- Адаптация для мобильных экранов.

## Каталоги
- **Расклады Насти:** отношения и чувства, динамика, выбор и жизненные ситуации.
- **Практики Аллы:** матрица, карма мужского и женского рода, родовой квадрат, предназначение и комплексный разбор родовых программ.
- **Совместные МАК-практики:** «Тайна рода» и «Наказ рода».

Названия и описания в каталоге — рабочая редакция для согласования с авторами. Стоимости не указаны и оставлены как «уточняется».

## Файлы
- `index.html` — страницы, каталоги, формы записи и кабинета.
- `styles.css` — дизайн и адаптивность.
- `app.js` — демонстрационная логика записи и кабинета.
- `.github/workflows/deploy.yml` — автоматическая публикация на GitHub Pages.

## Публикация
GitHub Actions запускает публикацию при push в `main`. Для GitHub Pages в настройках репозитория должен быть выбран источник **GitHub Actions**.

## Ограничения и безопасность
Это демонстрационный frontend, не готовый сервис для приёма реальных клиентских данных. Нет серверной авторизации, общей базы данных, серверной проверки слотов, онлайн-оплаты и отправки уведомлений. Все заявки хранятся в локальном браузере и не видны другому устройству. Пароль администратора предназначен только для демонстрации и не обеспечивает защиту. До коммерческого запуска требуется backend, безопасная авторизация и разграничение доступа, база данных, защита персональных данных, серверное расписание, политика конфиденциальности и согласия на обработку данных.
